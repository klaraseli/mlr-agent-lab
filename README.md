# mlr-agent-lab

Experiments and coursework for **MLR** (7th semester), plus a scratch space for
agent tooling.

## Contents

Nothing here yet — this repository starts as a clean scaffold so course
materials and agent experiments can be added deliberately.

## Getting started

This repo uses [uv](https://docs.astral.sh/uv/) for Python environments and
dependency management.

```bash
uv init            # if you want a pyproject.toml
uv run python      # run Python inside the project environment
uv add <package>   # add a dependency
```
